# Security Policy

## Scope

This repository contains documentation, diagrams and sanitized example data
for the XRPL Lending Terminal. It does not contain the production Terminal
implementation.

Security reports that concern the Terminal product itself, the XRPL Lending
Network market interface, or infrastructure operated by XRPL Lending Network
are still welcome through the contact below.

Issues in the XRP Ledger Lending Protocol (XLS-65, XLS-66) or in `rippled`
should be reported to the XRP Ledger Foundation and Ripple through the
[XRPL bug bounty](https://xrpl.org/resources/contribute-code/report-a-bug)
process, not here.

## Reporting

Please do **not** open public GitHub issues for security problems.

Contact: dev@xrpl-lending.network

Include:

- a description of the issue and its impact;
- steps to reproduce, if applicable;
- the network involved (Devnet, Testnet, Mainnet), if applicable.

We aim to acknowledge reports within five business days.

## Disclosure

Please give us a reasonable amount of time to investigate and address the
issue before any public disclosure. We will coordinate the timing with you.
